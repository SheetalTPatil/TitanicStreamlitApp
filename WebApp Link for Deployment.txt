
Local run process-
1) Install Streamlit:

pip install streamlit pandas joblib scikit-learn  (Needed to Run Once only)

2)Run the code file(main python file in which model is build): 

Python 7AssLogisticRegression.ipynb	  (Needed to Run Once only)
This will create:
titanic_model.pkl

3) Run the App:
streamlit run app.py
